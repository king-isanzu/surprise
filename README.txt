A LITTLE LOVE SURPRISE — README

Jinsi ya kutumia:
1. Fungua ZIP na extract folder.
2. Fungua folder kwenye Visual Studio Code.
3. Fungua index.html.
4. Bonyeza right-click > Open with Live Server (kama una Live Server extension), au fungua index.html kwenye browser.

Kuweka online:
- Upload index.html kwenye GitHub repository au Netlify.
- Picha za Unsplash zinahitaji intaneti; kama URL ya picha haifanyi kazi, badilisha URL au pakua picha na uweke ndani ya folder lako.
- Hakuna Unsplash API key inayohitajika; picha zinatumia URL za picha moja kwa moja.

Ukurasa una kurasa 10, ujumbe wa Kiswahili, uchaguzi wa siku/muda/shughuli/aina ya eneo, maua na mioyo ya animation, countdown na surprise ya mwisho.
Kumbuka: DISAGREE inaheshimiwa na haikimbii wala kumlazimisha mtu kukubali.
